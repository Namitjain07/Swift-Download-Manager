Swift Download Manager Helper - browser add-on (version 1.2.0)

It sends the downloads you start in your browser to Swift Download Manager, adds
"Download with Swift Download Manager" to the right-click menu, passes your login
for the site along, and spots videos and sounds a page plays.
The app must be running for downloads to go to it; otherwise the browser downloads as usual.

Chrome, Edge, Brave or Opera
  1. Unzip SwiftDownloadManager-Helper-1.2.0-chrome.zip into a folder you keep
     (the folder "chrome-unpacked" here is the same thing, already unzipped).
  2. Open the extensions page: chrome://extensions  (Edge: edge://extensions)
  3. Turn on "Developer mode" (top right).
  4. Click "Load unpacked" and choose that folder.
  To put it in the Chrome Web Store or Edge Add-ons store, upload the .zip there
  (needs a developer account).

Firefox
  - To try it now: open about:debugging, click "This Firefox", "Load Temporary Add-on…"
    and choose SwiftDownloadManager-Helper-1.2.0-firefox.xpi. (Temporary add-ons are
    removed when Firefox closes.)
  - To install it for good, Firefox needs it signed: upload the .xpi at
    https://addons.mozilla.org/developers/ (free account; you can choose
    "On your own" to get a signed file back for yourself).
    Firefox Developer Edition or Nightly can also install it unsigned after setting
    xpinstall.signatures.required to false in about:config.

Both packages were tested with a real Chrome and a real Firefox: a download
that needs a login was caught and finished correctly in the app.
