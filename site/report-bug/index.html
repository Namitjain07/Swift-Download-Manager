A security problem?

Please do not post it in public. Report it privately; the security policy explains how.

Good to include

  • The exact message the app showed.
  • Whether it happens with every link or just one, and whether the server supports resuming.
  • Your speed limit, proxy and number of connections.
  • A screenshot: you can drag images into the GitHub page that opens.

Finding your version

  1. Open the app.
  2. Choose Help → About.
  3. Or, from a terminal: swift_download_manager --version.

The app's Help → Report a bug opens this page with the version and your system already filled in.
