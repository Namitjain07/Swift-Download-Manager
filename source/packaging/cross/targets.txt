# The platforms the cross-compile image builds for. One line per platform, columns separated by spaces:
#
#   name         the name used in the file name of the archive and on the command line
#   rust-target  the Rust target triple
#   glibc        the oldest glibc the program is linked against (Linux "gnu" targets), or - for everything else
#   kind         gui    = the window, the web interface and the command-line modes
#                server = no window: the web interface and the command-line modes only (a static program cannot load the
#                         OpenGL and X11/Wayland libraries that a window needs)
#   file-says    a piece of what `file` prints for a correct program for this platform (the build fails the check if it is
#                not there; an underscore stands for a space)
#   platform     the Docker platform to try the program on with `cross.sh test` (QEMU emulates it), or -
#   test-image   the image to try it in, or -
#
# The Docker image adds every rust-target listed here (see Dockerfile) and build-cross.sh builds the ones asked for.
